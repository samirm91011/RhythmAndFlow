# Fonts

| Font | Use | Licence | Source |
|---|---|---|---|
| Open Sans (variable) | Body text. This is the Brand Blueprint's secondary typeface. | SIL Open Font Licence 1.1 | Google Fonts |
| Cormorant Garamond (variable, roman + italic) | Headings. **Stand-in** for Amaris (the primary brand typeface), because its files were not supplied. | SIL Open Font Licence 1.1 | Google Fonts |

The files are in `app/src/main/res/font/`. When the client supplies Amaris, add the font file there and change `HeadingFont` in `ui/theme/Theme.kt` (also listed in docs/REMINDERS.md).
